# AI Issues Sandbox

A sandbox environment for testing and experimenting with AI-assisted workflows across the software development lifecycle (SDLC).

## Purpose

This project serves as an experiment base to explore how AI can augment and enhance different stages of software development. The goal is to generate hands-on content, working examples, and real experiences that feed into documentation and presentations on practical AI use in the SDLC.

## What We're Exploring

- AI-assisted issue triage and bug investigation
- Code generation, review, and refactoring with AI
- AI in testing: writing tests, identifying gaps, generating test cases
- Documentation generation and maintenance
- AI pair programming patterns and workflows
- Prompt engineering for engineering tasks

## Structure

Experiments are organized by scenario. Each scenario includes a setup, a problem to solve or task to perform, and notes on what worked, what didn't, and what was surprising.

## Audience

Content produced here is intended to support internal documentation, demos, and presentations aimed at engineering teams evaluating or adopting AI tooling in their development process.
