# MD040 — Fenced code blocks should have a language specified

Rules under test: [MD040](https://github.com/DavidAnson/markdownlint/blob/main/doc/md040.md)

The code blocks below intentionally omit the language specifier
to produce MD040 violations.

## List running processes

```
ps aux | grep java
```

## Hello World

```
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
```

## Fibonacci sequence

```
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
```

## Top customers by revenue

```
SELECT customer_id, SUM(amount) AS total_revenue
FROM orders
GROUP BY customer_id
ORDER BY total_revenue DESC
LIMIT 10;
```
