# MD024 — Multiple headings with the same content

Rules under test: [MD024](https://github.com/DavidAnson/markdownlint/blob/main/doc/md024.md)

The sections below intentionally repeat a heading and its content
to produce MD024 violations.

## Local Setup

Install dependencies and start the development server.

```bash
npm install
npm run dev
```

## Deployment

Push the latest build to the target environment and verify the health check endpoint.

```bash
npm run build
npm run deploy
```
